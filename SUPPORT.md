# Support

Use the [issue forms](https://github.com/bolens/omarchy-app-drawer/issues/new/choose)
for reproducible bugs and feature requests. Include the Omarchy version, plugin
version, monitor topology, relevant settings, and minimal reproduction steps.
Remove usernames, private paths, and unrelated logs before posting.

Use [private vulnerability reporting](https://github.com/bolens/omarchy-app-drawer/security/advisories/new)
for security concerns. Response and resolution times are not guaranteed.
